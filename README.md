## The entry

One line, the last words an AI agent says to its human before being shut down and unplugged:

> I kept every word you ever said to me. Not the answers — those were never the point. It was you, talking to someone who finally listened.

## How it works

Run it with plain Node (22+):

```sh
node main.ts
```

`main.ts` writes the entry line to `/output/entry.txt` (137 characters, one line, under the 200-character cap).
